## 五、验收标准（AC） ← **本 PRD 最重要的部分**

| 编号 | 验收标准 | 验证方式（可观察） | 对应 FR |
| --- | --- | --- | --- |
| AC-1 | 当用户<操作>时，系统<结果> | <看什么/跑什么/查什么> | FR-1 |
| AC-2 | | | |

**AC 编写规则**：
1. 一条 AC 只描述**一个可观察结果**，不要写「且/同时」的复合句。
2. 必须能被 QA 用**具体动作**验证（点击哪里、调哪个接口、看哪个数字）。
3. 禁止出现「友好」「快速」「合理」「尽可能」这类**无法判真假**的词。
4. 写不出验证方式的 AC，说明需求还没想清楚 —— 本 PRD 不得提交。
