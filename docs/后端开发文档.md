## 1. 技术选型与工程结构

### 1.1 选型

| 项 | 选择 | 说明 |
|---|---|---|
| 语言/框架 | **JDK 17 + Spring Boot 3.2.x** | 课程统一要求；`jakarta.*` 命名空间 |

## 2. 统一响应、异常与校验

### 2.1 错误码

| code | 含义 | 触发场景 |
|---|---|---|
| 0 | 成功 | — |
| 400 | 参数错误 | 日期格式非法、缺必填参数、`page<1`、`size>100`、`limit>50`、`sort` 字段不在白名单、CSV 文件为空/列数不符 |
| 404 | 资源不存在 | A6 订单号不存在、A19 taskId 不存在 |
| 409 | 状态冲突 | A18 同一文件（或全局）已有 `PROCESSING` 导入任务 |
| 500 | 服务器内部错误 | 未捕获异常兜底 |

```java
        Result<T> r = new Result<>();
```

```java
package com.example.dashboard.common;

import jakarta.validation.ConstraintViolationException;
import lombok.extern.slf4j.Slf4j;
import org.springframework.http.converter.HttpMessageNotReadableException;
import org.springframework.validation.BindException;
import org.springframework.web.bind.MethodArgumentNotValidException;
import org.springframework.web.bind.MissingServletRequestParameterException;
import org.springframework.web.bind.annotation.ExceptionHandler;
import org.springframework.web.bind.annotation.RestControllerAdvice;
import org.springframework.web.method.annotation.MethodArgumentTypeMismatchException;
import org.springframework.web.servlet.NoHandlerFoundException;

/** 全局异常处理：保证任何异常都以 {code,message,data} 结构返回 */
@Slf4j
@RestControllerAdvice
public class GlobalExceptionHandler {

    @ExceptionHandler(BizException.class)
    public Result<Void> handleBiz(BizException e) {
        log.warn("业务异常: {}", e.getMessage());
        return Result.fail(e.getErrorCode(), e.getMessage());
    }

    /** @Valid 校验失败（请求体/表单） */
    @ExceptionHandler({MethodArgumentNotValidException.class, BindException.class})
    public Result<Void> handleValid(BindException e) {
        String msg = e.getBindingResult().getFieldErrors().stream()
                .findFirst()
                .map(f -> f.getField() + " " + f.getDefaultMessage())
                .orElse(ErrorCode.BAD_REQUEST.getMessage());
        return Result.fail(ErrorCode.BAD_REQUEST, msg);
    }

    /** @RequestParam 校验失败（如 @Min/@Max） */
    @ExceptionHandler(ConstraintViolationException.class)
    public Result<Void> handleConstraint(ConstraintViolationException e) {
        return Result.fail(ErrorCode.BAD_REQUEST, e.getConstraintViolations().stream()
                .findFirst().map(v -> v.getMessage()).orElse(ErrorCode.BAD_REQUEST.getMessage()));
    }

    /** 日期格式非法 / 类型不匹配 / 缺少必填参数 -> 统一 400 */
    @ExceptionHandler({MethodArgumentTypeMismatchException.class,
                       MissingServletRequestParameterException.class,
                       HttpMessageNotReadableException.class})
    public Result<Void> handleBadRequest(Exception e) {
        log.warn("参数错误: {}", e.getMessage());
        return Result.fail(ErrorCode.BAD_REQUEST, "参数格式不正确：" + e.getMessage());
    }

    @ExceptionHandler(NoHandlerFoundException.class)
    public Result<Void> handleNotFound(NoHandlerFoundException e) {
        return Result.fail(ErrorCode.NOT_FOUND, "接口不存在：" + e.getRequestURL());
    }

    /** 兜底 500 */
    @ExceptionHandler(Exception.class)
    public Result<Void> handleOthers(Exception e) {
        log.error("系统异常", e);
        return Result.fail(ErrorCode.INTERNAL_ERROR, "服务器内部错误，请查看服务端日志");
    }
}
```

### 2.3 参数校验约定（**关键，决定错误码是否符合文档**）

| 参数 | 规则 | 违规返回 |
|---|---|---|
| `page` | `@Min(1)`，默认 1 | 400 |
| `size` | `@Min(1) @Max(100)`，默认 10 | 400 |
| `limit`（A4） | `@Min(1) @Max(50)`，默认 10 | 400 |
| `startDate`/`endDate` | `@Pattern(regexp="\\d{4}-\\d{2}-\\d{2}")`；缺省时**默认最近 30 天**；`start > end` → 400 | 400 |
| `granularity` | `day|week|month`，默认 `day` | 400 |
| `compareType` | `previous|previousYear`，默认 `previous` | 400 |
| `rankBy` | `sales|quantity`，默认 `sales` | 400 |
| `payType` | `alipay|wechat|card` | 400 |
| `userType` | `new|old` | 400 |
| `promoFlag` | `0|1` | 400 |
| `sort` | 格式 `field,asc|desc`；**字段白名单**：`orderTime,totalAmount,price,quantity` | 400 |
| `periodType` | 当前仅 `month` | 400 |
| `periodValue` | `yyyy-MM`，缺省 = 当前月 | 400 |
| A15 `startDate/endDate` | **必填**（`@NotBlank`） | 400 |

**日期边界统一用左闭右开**，避免 `23:59:59` 丢数据：

```sql
order_time >= #{startDate} AND order_time < DATE_ADD(#{endDate}, INTERVAL 1 DAY)
```

### 4.2 日期缺省与校验工具

```java
package com.example.dashboard.util;

import com.example.dashboard.common.BizException;
import com.example.dashboard.common.ErrorCode;

import java.time.LocalDate;
import java.time.format.DateTimeFormatter;

public final class DateRangeUtils {
    public static final DateTimeFormatter FMT = DateTimeFormatter.ofPattern("yyyy-MM-dd");

    private DateRangeUtils() {}

    /** 缺省最近 30 天（含今天）；start > end 报 400 */
    public static String[] normalize(String start, String end) {
        LocalDate e = (end == null || end.isBlank()) ? LocalDate.now() : LocalDate.parse(end, FMT);
        LocalDate s = (start == null || start.isBlank()) ? e.minusDays(29) : LocalDate.parse(start, FMT);
        if (s.isAfter(e)) {
            throw new BizException(ErrorCode.BAD_REQUEST, "startDate 不能晚于 endDate");
        }
        return new String[]{s.format(FMT), e.format(FMT)};
    }

    /** 环比：本期前一个等长区间；同比：去年同期 */
    public static String[] previousPeriod(String start, String end) {
        LocalDate s = LocalDate.parse(start, FMT);
        LocalDate e = LocalDate.parse(end, FMT);
        long days = java.time.temporal.ChronoUnit.DAYS.between(s, e) + 1;
        LocalDate pe = s.minusDays(1);
        LocalDate ps = pe.minusDays(days - 1);
        return new String[]{ps.format(FMT), pe.format(FMT)};
    }

    public static String[] previousYear(String start, String end) {
        return new String[]{
            LocalDate.parse(start, FMT).minusYears(1).format(FMT),
            LocalDate.parse(end, FMT).minusYears(1).format(FMT)
        };
    }
}
```

### 4.3 排序白名单（防 SQL 注入）

```java
package com.example.dashboard.util;

import com.example.dashboard.common.BizException;
import com.example.dashboard.common.ErrorCode;

import java.util.Map;
import java.util.Set;

public final class SqlSortWhitelist {
    /** 前端字段名 -> 数据库列名 */
    private static final Map<String, String> ORDER_SORT = Map.of(
            "orderTime", "order_time",
            "totalAmount", "total_amount",
            "price", "price",
            "quantity", "quantity"
    );
    private static final Set<String> DIRECTIONS = Set.of("asc", "desc");

    private SqlSortWhitelist() {}

    /** 解析 "totalAmount,desc" -> "total_amount DESC"；非法则 400 */
    public static String parseOrderSort(String sort) {
        if (sort == null || sort.isBlank()) return "order_time DESC";
        String[] parts = sort.split(",");
        if (parts.length != 2) {
            throw new BizException(ErrorCode.BAD_REQUEST, "sort 格式应为 字段,asc|desc");
        }
        String column = ORDER_SORT.get(parts[0].trim());
        String direction = parts[1].trim().toLowerCase();
        if (column == null || !DIRECTIONS.contains(direction)) {
            throw new BizException(ErrorCode.BAD_REQUEST, "不支持的排序字段或方向：" + sort);
        }
        return column + " " + direction.toUpperCase();
    }
}
```

### 4.4 时间粒度分组表达式（MySQL）

```sql
-- day:   2026-09-01
DATE_FORMAT(order_time, '%Y-%m-%d')
-- week:  2026-W38   （%x = ISO 年，%v = ISO 周，跨年周不会串年）
DATE_FORMAT(order_time, '%x-W%v')
-- month: 2026-09
DATE_FORMAT(order_time, '%Y-%m')
```

对应 Java 枚举：

```java
public enum Granularity {
    DAY("DATE_FORMAT(order_time, '%Y-%m-%d')"),
    WEEK("DATE_FORMAT(order_time, '%x-W%v')"),
    MONTH("DATE_FORMAT(order_time, '%Y-%m')");

    public final String expr;
    Granularity(String expr) { this.expr = expr; }

    public static Granularity of(String value) {
        if (value == null || value.isBlank()) return DAY;
        try {
            return valueOf(value.trim().toUpperCase());
        } catch (IllegalArgumentException e) {
            throw new BizException(ErrorCode.BAD_REQUEST, "granularity 仅支持 day/week/month");
        }
    }
}
```

### 4.5 空数据与 null 约定（**前端已按此实现，务必遵守**）

| 场景 | 后端返回 | 前端展示 |
|---|---|---|

### A2 `GET /api/orders` 订单分页查询

| 参数 | 类型 | 必填 | 默认 | 校验 |
|---|---|---|---|---|
| page | int | 否 | 1 | `@Min(1)` |
| size | int | 否 | 10 | `@Min(1) @Max(100)` |

```xml
  FROM orders
  <where>
    order_time &gt;= #{startDate} AND order_time &lt; DATE_ADD(#{endDate}, INTERVAL 1 DAY)
    <if test="category != null and category != ''">AND category = #{category}</if>
    <if test="payType  != null and payType  != ''">AND pay_type = #{payType}</if>
    <if test="userType != null and userType != ''">AND user_type = #{userType}</if>
    <if test="promoFlag != null">AND promo_flag = #{promoFlag}</if>
    <if test="keyword  != null and keyword  != ''">
      AND (order_id LIKE CONCAT('%', #{keyword}, '%') OR product_name LIKE CONCAT('%', #{keyword}, '%'))
    </if>
  </where>
  ORDER BY ${sortColumn} ${sortDirection}   <!-- 已被白名单校验 -->
  LIMIT #{offset}, #{size}
</select>
```

### A3 `GET /api/orders/kpi` KPI 汇总

参数：`category, startDate, endDate`（仅这三个，前端按此调用）。

一次查询拿到全部指标（**注意复购率需要二次聚合**）：

```sql
SELECT
  COALESCE(SUM(total_amount), 0)                                       AS total_sales,
  COUNT(*)                                                             AS total_orders,
  COALESCE(ROUND(SUM(total_amount) / NULLIF(COUNT(*), 0), 2), 0)       AS avg_order_value,
  COUNT(DISTINCT product_name)                                         AS hot_product_count,
  COUNT(DISTINCT user_id)                                              AS total_users,
  COUNT(DISTINCT CASE WHEN user_type = 'new' THEN user_id END)         AS new_user_count,
  (SELECT COUNT(*) FROM (
      SELECT user_id FROM orders
      WHERE order_time >= #{startDate} AND order_time < DATE_ADD(#{endDate}, INTERVAL 1 DAY)
        <if test="category != null and category != ''">AND category = #{category}</if>
      GROUP BY user_id HAVING COUNT(*) > 1
  ) t)                                                                 AS repurchase_users
FROM orders
WHERE order_time >= #{startDate} AND order_time < DATE_ADD(#{endDate}, INTERVAL 1 DAY)
  <if test="category != null and category != ''">AND category = #{category}</if>
```

派生：`newUserRate = totalUsers > 0 ? newUserCount / totalUsers : null`，`repurchaseRate = totalUsers > 0 ? repurchaseUsers / totalUsers : null`（**保留 4 位小数**，前端格式化为 2 位百分比）。

> 前端还会用同一接口查「上一个等长区间」以计算 KPI 环比，因此该接口必须支持任意历史区间且无状态。

### A7 `GET /api/orders/trend` 趋势对比（环比/同比）

参数：`granularity`、`compareType(previous|previousYear)`、`category`、`startDate`、`endDate`。

**实现步骤（务必按此口径，前端 tooltip 直接展示增长率）**：

1. 用 A5 的逻辑分别查「本期」与「对比期」的 `period → (sales, orders)`；
2. **按桶序号对齐**（两段长度相同、粒度相同，第 i 个桶互相对应，这是本接口最容易被写错的地方）；
3. 逐桶算 `salesGrowthRate = (cur - prev) / prev`，**prev 为 0 或缺失时返回 `null`**；
4. 返回 `currentPeriod`、`comparePeriod` 供前端展示区间。

```java
@Data
public class TrendItemVO {
    private String period;
    private BigDecimal currentSales;
    private Integer currentOrders;
    private BigDecimal prevSales;      // 对比期缺失时为 null
    private Integer prevOrders;
    private BigDecimal salesGrowthRate;   // null 表示数据不足
    private BigDecimal ordersGrowthRate;
}
```

- `compareType=previous`：对比期 = 本期前等长区间（`DateRangeUtils.previousPeriod`）；
- `compareType=previousYear`：对比期 = 去年同期（`previousYear`）；**数据不足一年时按文档返回空对比数据并把 growthRate 置 null**。

### A8 `GET /api/orders/price-distribution` 客单价区间分布

区间固定（**不要做成前端可传，除非同步改文档**）：`0-100 / 100-300 / 300-500 / 500-1000 / 1000-5000 / 5000以上`。

```sql
SELECT t.range_label AS `range`,
       COUNT(*) AS order_count,
       ROUND(SUM(t.total_amount), 2) AS sales
FROM (
  SELECT total_amount,
         CASE
           WHEN total_amount < 100  THEN '0-100'
           WHEN total_amount < 300  THEN '100-300'
           WHEN total_amount < 500  THEN '300-500'
           WHEN total_amount < 1000 THEN '500-1000'
           WHEN total_amount < 5000 THEN '1000-5000'
           ELSE '5000以上'
         END AS range_label
  FROM orders
  WHERE <时间 + 品类条件>
) t
GROUP BY t.range_label
ORDER BY MIN(t.total_amount)
```

Java 层补齐 6 个区间（无数据的区间补 0，保证直方图形状稳定）并算 `orderRatio = orderCount / totalOrders`（0~1 四位小数）。

### A9 `GET /api/orders/category-contribution` 品类贡献（帕累托）

```sql
SELECT category,
       sales,
       ROUND(sales / SUM(sales) OVER (), 4) AS sales_ratio,

             ROWS BETWEEN UNBOUNDED PRECEDING AND CURRENT ROW) / SUM(sales) OVER (), 4) AS cumulative_ratio
FROM (
  SELECT category, ROUND(SUM(total_amount), 2) AS sales
  FROM orders
  WHERE order_time >= #{startDate} AND order_time < DATE_ADD(#{endDate}, INTERVAL 1 DAY)
```

### A16 `GET /api/users/rfm` RFM 用户分层

参数：`startDate`、`endDate`（**缺省为最近 90 天**，与其它接口的 30 天默认不同，注意在 Controller 层单独处理）、`category`。

```sql
SELECT user_id,
       COUNT(*)                              AS frequency,
       ROUND(SUM(total_amount), 2)           AS monetary,
       DATEDIFF(#{windowEnd}, MAX(order_time)) AS recency_days
FROM orders
WHERE order_time >= #{startDate} AND order_time < DATE_ADD(#{endDate}, INTERVAL 1 DAY)
  <if test="category != null and category != ''">AND category = #{category}</if>
GROUP BY user_id
```

阈值与分层（**分位法：中位数，抗极值**——面试高频追问点）：

```java
int rThreshold = median(users.map(RfmUser::getRecencyDays));   // R：越小越近
int fThreshold = median(users.map(RfmUser::getFrequency));
BigDecimal mThreshold = median(users.map(RfmUser::getMonetary));

// R/F/M 各二分（R 高 = 最近有购买），组合 8 类
String key = (recency <= rThreshold ? "1" : "0")
           + (frequency >= Math.max(1, fThreshold) ? "1" : "0")
           + (monetary.compareTo(mThreshold) >= 0 ? "1" : "0");
```

| key | 分层名称 |
|---|---|
| 111 | 重要价值客户 |
| 011 | 重要保持客户 |
| 101 | 重要发展客户 |
| 001 | 重要挽留客户 |
| 110 | 一般价值客户 |
| 010 | 一般保持客户 |
| 100 | 一般发展客户 |
| 000 | 流失客户 |

返回：`{ windowStart, windowEnd, thresholds:{rDays,fCount,mAmount}, totalUsers, totalSales, segments:[{segment,userCount,sales,salesRatio,avgOrderValue,avgFrequency}] }`，`segments` 按 `sales` 降序；无用户时 `segments: []`。

> **实现建议**：用户量通常 < 10 万，直接在 Java 侧算中位数与分层（一条 SQL 取明细 + 内存聚合），比 SQL 里做中位数（`ROW_NUMBER` 双查询）更清晰、更易单测。JPA 团队注意，这是 3 处需改写的复杂查询之二。

## 6. 异步导入任务设计

### 6.1 状态机

```
POST /import ──► PROCESSING ──┬─► SUCCESS（errorRows = 0）
                              ├─► PARTIAL（validRows > 0 且 errorRows > 0）
                              └─► FAILED（validRows = 0，或文件级异常）
```

### 6.2 线程池

```java
@Configuration
@EnableAsync
public class AsyncConfig {
    @Bean("importExecutor")
    public ThreadPoolTaskExecutor importExecutor() {
        ThreadPoolTaskExecutor executor = new ThreadPoolTaskExecutor();
        executor.setCorePoolSize(2);
        executor.setMaxPoolSize(4);
        executor.setQueueCapacity(50);
        executor.setThreadNamePrefix("csv-import-");
        // 队列满时由调用线程执行，避免任务被静默丢弃
        executor.setRejectedExecutionHandler(new ThreadPoolExecutor.CallerRunsPolicy());
        executor.initialize();
        return executor;
    }
}
```

### 6.3 受理逻辑（含 409 判定）

```java
@Service
@RequiredArgsConstructor
public class OrderImportService {

    private final ImportTaskMapper taskMapper;
    private final OrderMapper orderMapper;
    private final ImportTaskExecutor executor;

    @Transactional
    public ImportTaskVO submit(MultipartFile file, int append) throws IOException {
        if (file == null || file.isEmpty()) {
            throw new BizException(ErrorCode.BAD_REQUEST, "文件为空");
        }
        String name = StringUtils.hasText(file.getOriginalFilename()) ? file.getOriginalFilename() : "upload.csv";
        if (!name.toLowerCase().endsWith(".csv")) {
            throw new BizException(ErrorCode.BAD_REQUEST, "仅支持 .csv 文件");
        }
        byte[] bytes = file.getBytes();
        String hash = DigestUtils.sha256Hex(bytes);

        // 409：同源文件或全局已有处理中任务
        if (taskMapper.countProcessingByHash(hash) > 0 || taskMapper.countProcessing() > 0) {
            throw new BizException(ErrorCode.CONFLICT, "已有导入任务正在处理中，请稍后再试");
        }

        ImportTaskEntity task = new ImportTaskEntity();
        task.setTaskId("imp_" + LocalDateTime.now().format(DateTimeFormatter.ofPattern("yyyyMMdd_HHmmssSSS")));
        task.setFileName(name);
        task.setFileHash(hash);
        task.setAppendMode(append);
        task.setStatus("PROCESSING");
        task.setStartTime(LocalDateTime.now());
        taskMapper.insert(task);

        executor.runAsync(task.getTaskId(), bytes, append);   // 异步
        return new ImportTaskVO(task.getTaskId(), "PROCESSING");
    }
}
```

### 6.4 执行逻辑（逐行校验 + 批量写入 + 错误明细）

```java
@Slf4j
@Component
@RequiredArgsConstructor
public class ImportTaskExecutor {

    private static final int BATCH_SIZE = 500;
    private static final int MAX_ERRORS = 500;      // 明细留存上限
    private static final Set<String> PAY_TYPES = Set.of("alipay", "wechat", "card");
    private static final Set<String> USER_TYPES = Set.of("new", "old");
    private static final DateTimeFormatter TIME_FMT = DateTimeFormatter.ofPattern("yyyy-MM-dd HH:mm:ss");
    private static final BigDecimal TOLERANCE = new BigDecimal("0.01");

    private final ImportTaskMapper taskMapper;
    private final ImportTaskErrorMapper errorMapper;
    private final OrderMapper orderMapper;

    @Async("importExecutor")
    public void runAsync(String taskId, byte[] bytes, int append) {
        int total = 0, valid = 0, errors = 0;
        List<ImportTaskErrorEntity> errorBatch = new ArrayList<>();
        try (BufferedReader reader = new BufferedReader(
                new InputStreamReader(new ByteArrayInputStream(bytes), StandardCharsets.UTF_8))) {

            if (append == 0) {
                orderMapper.truncateOrders();          // 覆盖导入：清空（同事务外，见下方注意）
            }

            String line;
            int lineNo = 0;
            boolean firstLine = true;
            List<OrderEntity> buffer = new ArrayList<>(BATCH_SIZE);

            while ((line = reader.readLine()) != null) {
                lineNo++;
                if (firstLine && isHeader(line)) { firstLine = false; continue; }  // 兼容有/无表头
                firstLine = false;
                if (line.isBlank()) continue;
                total++;

                List<String> cols = CsvUtils.split(line);
                String error = validate(cols);
                if (error != null) {
                    errors++;
                    if (errorBatch.size() < MAX_ERRORS) {
                        errorBatch.add(new ImportTaskErrorEntity(taskId, lineNo, CsvUtils.fieldOf(error), CsvUtils.msgOf(error)));
                    }
                    continue;
                }
                buffer.add(toEntity(cols));
                valid++;

                if (buffer.size() >= BATCH_SIZE) {
                    orderMapper.batchInsert(buffer);       // 500 行一次，避免逐条往返
                    buffer.clear();
                }
            }
            if (!buffer.isEmpty()) orderMapper.batchInsert(buffer);

        } catch (Exception e) {
            log.error("导入任务失败 taskId={}", taskId, e);
            taskMapper.finish(taskId, valid == 0 ? "FAILED" : "PARTIAL", total, valid, errors,
                    LocalDateTime.now(), StringUtils.truncate(e.getMessage(), 500));
            saveErrors(taskId, errorBatch);
            return;
        }

        String status = errors == 0 ? "SUCCESS" : (valid > 0 ? "PARTIAL" : "FAILED");
        taskMapper.finish(taskId, status, total, valid, errors, LocalDateTime.now(), null);
        saveErrors(taskId, errorBatch);
        log.info("导入完成 taskId={} total={} valid={} error={} status={}", taskId, total, valid, errors, status);
    }

    /** 返回 null 表示校验通过；否则返回 "field|message" */
    private String validate(List<String> c) {
        if (c.size() != 10) return "row|列数必须为 10 列，当前 " + c.size();
        String[] f = { "orderId", "productName", "category", "price", "quantity",
                       "totalAmount", "orderTime", "userId", "userType", "payType" };
        for (int i = 0; i < 10; i++) if (StringUtils.isBlank(c.get(i))) return f[i] + "|必填字段缺失";
        BigDecimal price, total; Integer qty;
        try { price = new BigDecimal(c.get(3)); } catch (Exception e) { return "price|单价格式非法"; }
        try { qty = Integer.valueOf(c.get(4)); } catch (Exception e) { return "quantity|数量格式非法"; }
        try { total = new BigDecimal(c.get(5)); } catch (Exception e) { return "totalAmount|总金额格式非法"; }
        if (price.signum() <= 0) return "price|单价必须为正数";
        if (qty <= 0) return "quantity|数量必须为正数";
        if (price.multiply(BigDecimal.valueOf(qty)).subtract(total).abs().compareTo(TOLERANCE) > 0) {
            return "totalAmount|总金额与单价×数量不一致";
        }
        try { LocalDateTime.parse(c.get(6), TIME_FMT); } catch (Exception e) { return "orderTime|日期格式非法"; }
        if (!USER_TYPES.contains(c.get(8))) return "userType|用户类型枚举非法";
        if (!PAY_TYPES.contains(c.get(9))) return "payType|支付方式枚举非法";
        return null;
    }
}
```

**注意事项**

1. **覆盖导入的清空与写入要在同一事务内**（否则清空成功、写入失败会丢数据）。上面为可读性写在执行器里，正式实现建议：
   ```java
   @Transactional
   public void replaceAll(List<OrderEntity> batch) { orderMapper.truncateOrders(); orderMapper.batchInsert(batch); }
   ```
   更稳的做法是「先写临时表 → 校验通过后 `RENAME TABLE` 原子切换」。
2. **`batchInsert` 用 `INSERT INTO ... VALUES (...),(...)...`** 或 MP 的 `saveBatch`，`rewriteBatchedStatements=true` 能显著提速（JDBC URL 见 §8）。
3. **失败行不中断导入**（文档要求），逐行记录错误。
4. **错误明细写入用批量插入**，避免 5000 次单条 insert。
5. 导入完成后：`@CacheEvict(allEntries = true)` 清理 A1 品类缓存，（若启用）刷新 `daily_summary`。

## 7. CSV 流式导出设计

```java
@GetMapping("/api/orders/export")
public ResponseEntity<StreamingResponseBody> export(OrderQuery query) {
    String[] range = DateRangeUtils.normalize(query.getStartDate(), query.getEndDate());
    query.setStartDate(range[0]);
    query.setEndDate(range[1]);

    String filename = "orders_%s_%s.csv".formatted(
            range[0].replace("-", ""), range[1].replace("-", ""));

    StreamingResponseBody body = outputStream -> {
        // BOM：Excel 打开中文不乱码；若仅用于程序二次解析可注释掉
        outputStream.write(new byte[]{(byte) 0xEF, (byte) 0xBB, (byte) 0xBF});
        try (Writer w = new OutputStreamWriter(outputStream, StandardCharsets.UTF_8);
             BufferedWriter bw = new BufferedWriter(w)) {
            bw.write("订单号,商品名,品类,单价,数量,总金额,下单时间,用户ID,用户类型,支付方式\n");
            long lastId = 0;                       // 游标分页，避免 OFFSET 深翻页
            while (true) {
                List<OrderEntity> batch = orderMapper.exportBatch(query, lastId, 1000);
                if (batch.isEmpty()) break;
                for (OrderEntity o : batch) {
                    bw.write(CsvUtils.line(o));
                    bw.write('\n');
                    lastId = o.getId();
                }
                bw.flush();
            }
        }
    };

    return ResponseEntity.ok()
            .header(HttpHeaders.CONTENT_DISPOSITION,
                    "attachment; filename=\"" + filename + "\"")
            .contentType(MediaType.parseMediaType("text/csv; charset=UTF-8"))
            .body(body);
}
```

```sql
         order_time, user_id, user_type, pay_type, promo_flag, region
  FROM orders
  <where>
    order_time &gt;= #{q.startDate} AND order_time &lt; DATE_ADD(#{q.endDate}, INTERVAL 1 DAY)
    <if test="lastId > 0">AND id &gt; #{lastId}</if>
    <if test="q.category != null and q.category != ''">AND category = #{q.category}</if>
    <if test="q.keyword != null and q.keyword != ''">
      AND (order_id LIKE CONCAT('%',#{q.keyword},'%') OR product_name LIKE CONCAT('%',#{q.keyword},'%'))
    </if>
    <if test="q.payType != null and q.payType != ''">AND pay_type = #{q.payType}</if>
    <if test="q.userType != null and q.userType != ''">AND user_type = #{q.userType}</if>
  </where>
  ORDER BY id ASC
  LIMIT #{size}
</select>
```

```java
public static String escape(String v) {
    if (v == null) return "";
    return (v.contains(",") || v.contains("\"") || v.contains("\n") || v.contains("\r"))
            ? '"' + v.replace("\"", "\"\"") + '"' : v;
}
```

### 9.5 面试高频追问预案（写进答辩稿）

| 追问 | 回答要点 |
|---|---|
| 达成率 70% 是怎么算的 | `achieved/target`；`dailyNeeded = max(0, target-achieved)/剩余自然日`；已结束周期剩余天数为 0，`dailyNeeded=0` |
| 同比为什么可能为 null | 数据不足一年 → 无对比期 → `growthRate=null`，前端展示「无对比数据」，**不能假造 0** |
| 环比口径 | 本期前等长区间（按自然日天数对齐），跨月/跨年都成立；`DateRangeUtils.previousPeriod` 单测覆盖 2 月、月末边界 |
| 帕累托累计占比怎么算 | `SUM(sales) OVER (ORDER BY sales DESC ROWS UNBOUNDED PRECEDING)`；80% 参考线在前端画 |
| RFM 阈值为什么用中位数 | 分位数抗极值（少数超级买家会拉高均值，导致分层失真）；中位数实现简单、可解释 |
| 导入 5000 行为什么不慢 | 流式读取 + 每 500 行批量插入 + `rewriteBatchedStatements`；失败行不中断、错误批量落表 |
| 导出百万行会不会 OOM | 流式写出 + 游标分页，内存中只有 1000 行批次 |

```dockerfile
# ---- 构建阶段 ----
FROM maven:3.9-eclipse-temurin-17 AS build
WORKDIR /app
COPY pom.xml .
RUN mvn -B dependency:go-offline
COPY src ./src
RUN mvn -B clean package -DskipTests

# ---- 运行阶段 ----
FROM eclipse-temurin:17-jre-alpine
WORKDIR /app
COPY --from=build /app/target/*.jar app.jar
ENV JAVA_OPTS="-Xms256m -Xmx512m -Duser.timezone=Asia/Shanghai"
EXPOSE 8080
ENTRYPOINT ["sh", "-c", "java $JAVA_OPTS -jar app.jar"]
```

### 11.2 docker-compose.yml

```yaml
services:
  mysql:
    image: mysql:8.0
    environment:
      MYSQL_ROOT_PASSWORD: root
      MYSQL_DATABASE: esd_dashboard
      TZ: Asia/Shanghai
    ports: ["3306:3306"]
    volumes:
      - ./db/schema.sql:/docker-entrypoint-initdb.d/01-schema.sql
      - ./data/out/init-data.sql:/docker-entrypoint-initdb.d/02-data.sql   # ETL 产物
      - mysql-data:/var/lib/mysql
    command: --character-set-server=utf8mb4 --collation-server=utf8mb4_unicode_ci

  app:
    build: .
    depends_on: [mysql]
    environment:
      SPRING_DATASOURCE_URL: jdbc:mysql://mysql:3306/esd_dashboard?useUnicode=true&characterEncoding=utf8&serverTimezone=Asia/Shanghai&rewriteBatchedStatements=true
      SPRING_DATASOURCE_USERNAME: root
      SPRING_DATASOURCE_PASSWORD: root
    ports: ["8080:8080"]

volumes:
  mysql-data:
```

## 12. 前后端联调验收清单

**这张表就是「后端是否合格」的判定标准**（前端已按此实现，逐条勾选即可）：

| # | 验收项 | 判定方式 |
|---|---|---|
| 1 | 所有接口返回 `{code,message,data}`，成功 `code=0` | 任意接口 |
| 2 | 业务失败返回 `code` 非 0 且 `message` 为中文可读文案 | 触发 400/404/409 |
| 3 | `page=0` / `size=101` 返回 400 | curl |
| 4 | 不存在的订单号返回 404 | `GET /api/orders/XXX` |
| 5 | 进度接口不存在的 taskId 返回 404 | `GET /api/orders/import/tasks/xxx` |
| 6 | 日期参数严格 `yyyy-MM-dd`，缺省 = 最近 30 天 | 不带日期调 A3，看是否等于近 30 天 |
| 7 | 比率字段为 0~1 小数 | A3 `newUserRate` |
| 8 | 无法计算的增长率为 `null`（不是 0、不是 1） | A7 数据不足区间 |
| 9 | A10 恰好返回 24 个元素 | `.hours.length === 24` |
| 10 | A8 返回 6 个固定区间 | `.intervals.length === 6` |
| 11 | A9 的 `cumulativeRatio` 递增且末项 = 1 | 检查数组 |
| 12 | A17 的 `region` 为中文省份（或州码，前端会降级） | 检查数据 |
| 13 | A12 返回 `text/csv` + `Content-Disposition` 文件名 | curl -D - |
| 14 | A12 导出的 CSV 可被 A18 直接重新导入（round-trip） | 导出后上传，`validRows ≈ totalRows` |
| 15 | A18 受理后立即返回 `taskId`，状态为 `PROCESSING` | 观察响应时间 < 1s |
| 16 | A19 轮询能看到 `PROCESSING → SUCCESS/PARTIAL/FAILED` | 前端导入弹窗 |
| 17 | A18 重复提交同文件且前者未完成时返回 409 | 连续两次上传 |
| 18 | 导入的 `errors[].row` 与 CSV 实际行号一致（含表头计数） | 故意造几行脏数据 |
| 19 | 导入后看板 KPI/趋势立即反映新数据 | 点「刷新数据」 |
| 20 | `null` 字段不被 Jackson 剔除 | 看 A7 响应是否含 `prevSales: null` |
| 21 | 前端导出中文文件名不乱码 | 下载后看文件名与内容 |
| 22 | Swagger 可访问且分组清晰 | `/swagger-ui.html` |
| 23 | 无 CORS 报错（直连 5173 / 经 nginx 80） | 浏览器控制台 |
| 24 | 空库时前端显示虚线占位「暂无数据」而非报错 | 清空表后刷新页面 |

## 附录 A：若使用 Spring Data JPA 的等价写法（3 处需改写）

| 接口 | MyBatis-Plus 方案 | JPA 等价方案 |
|---|---|---|
| A9 帕累托 | `SUM(sales) OVER (...)` | 用 `@Query` 取分组销售额，在 Service 里循环累加算 `cumulativeRatio`（更易单测） |
| A16 RFM | 取明细后在 Java 算中位数 | 同上（推荐）；若必须 SQL，用 `ROW_NUMBER() OVER (ORDER BY x)` 双查询取中位 |
| A7 趋势 | 两次查询按桶序号对齐 | 建议同上（Service 内用 `List<PeriodItem>` 对齐并计算增长率） |

其余接口只用到 `GROUP BY` + `CASE WHEN`，`@Query(nativeQuery = true)` 可直接复用本文件 SQL。
