# 电商销售数据洞察看板 — 前端需求文档

> 保存日期：2026-04-11
> 状态：待补充《电商销售数据洞察看板开发接口文档》（19 个接口 A1~A19 的详细字段）

---

## 一、技术栈要求（硬性）

- Vue3 + `<script setup>` + Vite
- Element-Plus（UI 组件库）
- ECharts 5（图表）
- Axios（HTTP）
- Pinia（状态管理）
- dayjs（日期处理）
- **禁止使用 Vue2，不引入多余第三方库**

## 二、后端基础信息

- baseURL：`http://localhost:8080/api`
- 共 19 个 REST 接口（编号 A1 ~ A19）
- 统一返回格式：`{ code, message, data }`，`code = 0` 代表成功
- 错误码 400 / 404 / 409 / 500 统一处理
- 部分接口支持 CSV 导出（Blob 下载）
- 文件导入使用 `multipart/form-data`
- 导入后需轮询任务接口获取处理状态

## 三、需要实现的全部业务功能

### 1. 顶部 KPI 卡片
- 调用 **A3** 接口展示：总销售额、订单数、客单价、复购率等指标
- 金额保留 2 位小数

### 2. 公共筛选栏组件
- 品类下拉（**A1** 接口获取品类列表）
- 日期范围选择、支付方式、用户类型筛选
- 筛选条件**全局共享**（Pinia），筛选变更后所有图表、表格同时重新请求接口

### 3. 各类 ECharts 图表
| 接口 | 图表 |
|---|---|
| A5 / A7 | 销售趋势图：普通趋势、环比同比双线对比 |
| A4 | 商品 TOP10 横向柱状图（销售额/销量切换） |
| A9 | 品类贡献帕累托图：柱状图 + 累计占比双轴折线组合图 |
| A8 | 客单价区间分布直方图 |
| A10 | 24 小时下单时段分布图 |
| A11 | 新老用户、支付方式饼图 |
| A13 / A14 | 销售目标达成率环形仪表盘 |
| A16 | RFM 用户分层柱状/环形图 |
| A17 | 地域销售地图（ECharts 中国地图） |

⚠️ 所有图表必须处理 **loading 加载状态、空数据状态**；兼容后端返回 `null`、空数组等边界情况。

### 4. 订单明细模块
- **A2** 接口实现分页数据表格，支持多条件筛选
- 表格行点击调用 **A6** 接口，弹窗展示单条订单完整详情

### 5. 文件操作功能
- CSV 导出按钮：调用 **A12**，Blob 方式下载 csv 文件
- CSV 批量导入弹窗：选择本地文件，调用 **A18** 上传；拿到 taskId 后定时器轮询 **A19** 接口，直到任务终态 `SUCCESS` / `PARTIAL` / `FAILED`，展示导入统计报告与错误行
- **组件销毁务必清除定时器，避免内存泄漏**

## 五、编码约束

1. axios 拦截器统一判断 `code !== 0`，使用 `ElMessage` 抛出错误提示，业务组件不重复写 `if (code !== 0)`
2. 使用 Pinia 管理全部筛选参数，组件之间不要大量父子传参
3. dayjs 处理日期，快速生成近 7 天、近 30 天、近 90 天默认时间范围，参数格式严格 `yyyy-MM-dd`
4. 处理边界：无数据、增长率为 null、空列表
5. 导入轮询：`onUnmounted` 清除定时器，防止内存泄露
6. 样式使用 `scss scoped`；页面整体 BI 看板风格，配色简洁商务

## 六、输出要求

1. 输出关键文件完整代码，重要代码加注释
2. 给出 `main.js` 必要注册代码（element-plus、echarts、pinia）

4. 不写伪代码，代码尽量可以直接复制运行

## 附录：19 个接口与前端实现对照表（已按接口文档 V1.1 补齐）

| 编号 | 用途 | 方法/路径 | 请求参数 | 关键返回字段 |
|---|---|---|---|---|
| A1 | 品类列表 | GET /api/categories | 无 | `[{category, productCount}]` |
| A2 | 订单分页查询 | GET /api/orders | page, size, category, keyword, payType, userType, promoFlag, startDate, endDate, sort | `{total, page, size, records[]}` |
| A3 | KPI 汇总 | GET /api/orders/kpi | category, startDate, endDate | totalSales, totalOrders, avgOrderValue, hotProductCount, totalUsers, newUserRate, repurchaseRate |
| A4 | 商品 TOP10 | GET /api/orders/ranking | rankBy(sales/quantity), category, startDate, endDate, limit | `[{rank, productName, sales, quantity}]` |
| A5 | 时间粒度聚合 | GET /api/orders/stats | granularity(day/week/month), category, startDate, endDate | `{granularity, items:[{period, sales, orders}]}` |
| A6 | 订单详情 | GET /api/orders/{id} | 路径参数 id | 订单完整字段（404 表示不存在） |
| A7 | 趋势对比 | GET /api/orders/trend | granularity, compareType(previous/previousYear), category, startDate, endDate | currentPeriod, comparePeriod, items[{period, currentSales, prevSales, salesGrowthRate(null 兼容), ...}] |
| A8 | 客单价区间分布 | GET /api/orders/price-distribution | category, startDate, endDate | totalOrders, totalSales, intervals[{range, orderCount, sales, orderRatio}] |
| A9 | 品类贡献（帕累托） | GET /api/orders/category-contribution | startDate, endDate（无 category） | totalSales, items[{rank, category, sales, salesRatio, cumulativeRatio}] |
| A10 | 下单时段分析 | GET /api/orders/hourly | category, startDate, endDate | hours[{hour, orderCount, sales}]（固定 24 条） |
| A11 | 用户分析 | GET /api/orders/user-analysis | category, startDate, endDate | newUserCount/oldUserCount、newUserSales/oldUserSales、newUserRate、repurchaseRate、payTypeRates[] |
| A12 | CSV 导出 | GET /api/orders/export | category, keyword, payType, userType, startDate, endDate | Blob（text/csv + Content-Disposition） |
| A13 | 销售目标列表 | GET /api/targets | periodType(month), periodValue(yyyy-MM), category | `{periodType, periodValue, items:[{id, category, targetAmount}]}` |
| A14 | 目标达成率 | GET /api/orders/target-progress | periodType, periodValue, category | totalTarget, achievedSales, achievementRate, remainingDays, dailyNeeded, items[] |
| A15 | 促销活动效果 | GET /api/orders/campaign-effect | startDate(必填), endDate(必填), category | activity/nonActivity、salesGrowthRate、ordersGrowthRate、promotionPullRate |
| A16 | RFM 用户分层 | GET /api/users/rfm | startDate, endDate, category（默认近 90 天） | windowStart/End, thresholds, segments[{segment, userCount, sales, salesRatio, avgOrderValue, avgFrequency}] |
| A17 | 地域销售分布 | GET /api/orders/region | startDate, endDate, category | items[{rank, region, sales, orderCount, salesRatio}] |
| A18 | CSV 批量导入 | POST /api/orders/import（multipart/form-data） | file, append(0 覆盖/1 追加) | `{taskId, status}` |
| A19 | 导入任务状态 | GET /api/orders/import/tasks/{taskId} | 路径参数 taskId | status(PROCESSING/SUCCESS/PARTIAL/FAILED)、totalRows、validRows、errorRows、errors[{row, field, message}] |
