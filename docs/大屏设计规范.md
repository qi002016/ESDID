## 四、图表配色语义（`src/components/charts/chartTheme.js`）

统一注册 ECharts 主题 `bi`（`echarts.init(el, 'bi')`），坐标轴、tooltip、legend、字体、分割线全部由主题下发，组件只声明业务配色：

| 业务含义 | 用色 |
|---|---|
| 销售额 / GMV / 主指标 | 主色蓝 `#3b82f6` |
| 订单量 / 用户数 | 紫 `#8b5cf6` |
| 销量 / 数量类次要指标 | 青 `#06b6d4` |
| 正向 / 达成 | 绿 `#10b981` |
| 参考线 / 峰值 / 需关注 | 橙 `#f59e0b` |
| 负向 / 流失风险 | 红 `#ef4444` |
| 中性 / 兜底 | 灰蓝 `#94a3b8` |

- tooltip：白底 + `#e5e7eb` 描边 + `0 8px 24px rgba(15,23,42,0.12)` 阴影 + 圆角 10px，内容用 `tooltipTitle/tooltipRow/tooltipDivider` 统一生成（label 左、值右、tabular-nums）。
- 渐变面积：`verticalGradient()`（折线面积）、`horizontalGradient()`（条形/柱子），不再手写 rgba。
- 地图热力：单色系（`#3b82f6` 由 6% 透明度递进到实色），不用彩虹渐变。

## 六、与原需求的差异说明（重要）

1. **第 4 张 KPI 用「复购率」而非「转化率」**：接口文档的 19 个接口中没有流量/曝光/会话类接口（无 UV/PV/加购数），无法计算真实转化率。为避免展示无数据支撑的指标，第 4 张卡改为同样来自 A3/A11 的**复购率**。若后端新增 `A20 /api/traffic/conversion`，把 `DashboardKpiCard.vue` 中第 4 项换成该接口即可（组件已按 4 项数组化，改一处即可）。
2. **GMV 卡为「区间合计」而非「今日」**：顶部日期范围选择器决定统计区间，卡片副信息展示「上期」值做对照；如需「今日 GMV」，把区间设为今天即可。
3. **环比口径**：KPI 环比 = 本期 vs **上一个等长区间**（`utils/format.js` 的 `previousRange()`），由 A3 调用两次计算，不依赖新接口。
4. **促销活动 ROI 来自 A15 多次调用**：A15 一次只返回一个活动期，组件并行请求「本年度 + 上一年度」的 618 / 双11 / 双12 / 黑五窗口 + 「当前筛选区间」，计算 ROI = 活动期 GMV ÷ 非活动期 GMV，并用 1.0x 参考线标注盈亏平衡；数据不足的窗口自动隐藏。
5. **RFM 使用分位阈值**（中位数）二分 R/F/M 组合 8 类，与文档 5.16 口径一致。
6. **原功能全部保留**：A4/A8/A9/A10/A13/A14 等图表移到总览页底部「深度分析」区，并可在「商品分析 / 营销活动 / 用户分析」菜单中单独查看。
