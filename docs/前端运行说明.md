```bash
cd D:\ESDID\frontend

```

> ⚠️ 本机 npm 默认缓存目录（`C:\Users\...\AppData\Local\npm-cache`）无写权限，必须用 `--cache D:\ESDID\.npm-cache` 指定本地缓存目录，否则报 `EPERM: operation not permitted`。


## 三、构建与部署

```bash

```

```powershell

Get-ChildItem $html -Exclude "50x.html" | Remove-Item -Recurse -Force
```

## 四、启动 nginx

```powershell
cd D:\ESDID\frontend\nginx-1.31.3\nginx-1.31.3
.\nginx.exe              # 启动
.\nginx.exe -s reload    # 重新加载配置
.\nginx.exe -s quit      # 停止
```

访问：**http://localhost/**（80 端口）

nginx 配置要点（`conf\nginx.conf`，原文件已备份为 `nginx.conf.bak`）：

| 配置 | 作用 |
|---|---|
| `location /` + `try_files $uri $uri/ /index.html` | SPA 路由回退 |
| `location /assets/` + `expires 30d` | 带 hash 的静态资源长期缓存 |
| `location /api/` → `proxy_pass http://127.0.0.1:8080/api/` | 反向代理后端，**浏览器同源无跨域** |
| `proxy_buffering off` + 300s 超时 | CSV 流式导出/大文件下载 |
| `client_max_body_size 50m` | CSV 批量导入上传 |
| `gzip on` | 静态资源压缩（ECharts/Element Plus 体积较大） |

## 六、环境注意事项

1. **npm 缓存目录无权限** → 见第一节，使用 `--cache` 参数。
2. **沙箱/权限敏感操作**：`npm install`、`npm run dev`、`npm run build` 需要启动子进程（esbuild/rollup），在某些受限环境下会被拦截，需放开进程创建权限。
3. **中国地图数据**：ECharts 5 不再内置地图，项目已把 GeoJSON 放在 `src/assets/geo/china.json`（34 个省级区域）并在组件内 `registerMap` 注册，**无需联网**；若后端返回的省份名与地图不匹配（如"广东省"），组件会自动标准化名称，完全不匹配时自动降级为排行榜柱状图。
4. **日期格式**：所有日期参数严格 `yyyy-MM-dd`（dayjs 生成），默认区间为近 30 天，提供近 7/30/90 天快捷选项。
5. **端口占用**：80（nginx）、5173（dev）、8080（后端）需保持可用。
