# 三件套独立部署说明

三个独立交付物，可分别部署到不同机器：

```
① Agent（本目录）
   dist\agent.exe     —— 独立可执行文件（PyInstaller 打包，自带 Python 运行时）
   dist\.env          —— 配置文件（必须与 agent.exe 放同一目录）
② 前端（frontend\dist）
   nginx 托管静态文件 + 反向代理（配置见 nginx-1.31.3\conf\nginx.conf）
③ 业务后端（backend\springboot-ES\target）
   springboot-ES-0.0.1-SNAPSHOT.jar  —— java -jar 直接运行（需 Java 17+）
```

## ① Agent 独立包（本目录 dist\）

### 目标机器要求

- **零 Python 环境**（exe 已内置运行时）
- 需要能访问：MySQL（业务数据）、Redis（会话记忆）；PostgreSQL（历史归档， **可选**，不可达自动降级）；Milvus（ **可选**，不可达自动本地向量检索）

### 启动

```bat
# 方式一：命令行前台运行（看日志）
dist\agent.exe

# 方式二：Windows 计划任务/服务 开机自启
schtasks /Create /TN "ESD-Agent" /TR "D:\路径\dist\agent.exe" /SC ONSTART /RL HIGHEST /F
```

### 配置

`dist\.env` 与 exe 同目录，按需修改：

```ini
DEEPSEEK_API_KEY=sk-xxx        # ★ 必填，否则降级 Mock
MYSQL_HOST=业务库IP             # 默认 127.0.0.1
REDIS_URL=redis://127.0.0.1:6379/0
PG_HOST=历史库IP               # 可选
MILVUS_HOST=向量库IP            # 可选
```

### 验证

```bat
curl http://127.0.0.1:8000/health
# 期望 db=true、history=postgres（或 off）、memory=redis
```

## ② 前端 + nginx（网关）

`nginx.conf` 已含三处关键配置：

- `location /`        → 前端静态文件（html 目录 = frontend\dist 内容）
- `location /api/`    → Spring Boot（8080）
- `location /agent/`  → Agent.exe（8000，`proxy_buffering off` 保证 SSE 流式实时）

启动：`nginx-1.31.3\nginx.exe`，浏览器访问 `http://localhost`。

## ③ Spring Boot

```bat
java -jar springboot-ES-0.0.1-SNAPSHOT.jar
# 需配置 application-dev.yml 的 MySQL 连接（与 Agent 共用业务库）
```

## 完整访问链路

```
浏览器 → nginx(80)
        ├─ /         → 前端页面
        ├─ /api/**   → Spring Boot(8080)  看板图表/表格
        └─ /agent/** → agent.exe(8000)    AI 智能问答（SSE 流式）
```

## 常见问题

- **Q：exe 启动后连不上数据库？** A：检查 `dist\.env` 是否与 exe 同目录、`MYSQL_HOST` 是否可达（防火墙/端口）。
- **Q：AI 问答没反应？** A：看 `DEEPSEEK_API_KEY` 是否已填；curl 验证 `/health` 后看 `logs`。
- **Q：历史会话看不到？** A：`history=off` 表示 PG 不可达，功能自动降级不影响对话；配好 `PG_*` 后重启 exe。
- **Q：重新打包？** A：改代码后执行 `pyinstaller agent.spec --noconfirm`，产物在 `dist\agent.exe`。
