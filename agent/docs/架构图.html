一次问答的 6 步（示例：上个月手机品类销售额环比）
① 前端 SSE 提交问题（session_id） ② Agent1 取 Redis 历史，消解「上个月」→ 2026-11 ③ Agent1 检索模板命中「环比」→ 生成条件聚合 SQL ④ 安全校验通过 → 只读执行 → 结果缓存 ⑤ Agent2 解读：手机环比 -49% + 折线图 spec ⑥ SSE 流式返回，前端渲染文字 + ECharts
注：Milvus 部署在虚拟机 Docker，当前未开机 → 自动降级本地向量检索（功能等价，接口不变）。
